# Tarot Journal（個人用タロット記録アプリ）

## できること
- 日付・テーマ・展開方法・写真・カード名・正逆位置・カードごとの個別メモ・解釈メモ・タグを保存
- スマートフォンのカメラ撮影または画像ファイルから写真を追加
- カード名を選択すると、メモ欄のカード一覧テンプレートを自動更新
- 78枚の標準タロット名リスト（カード名は自由入力も可能）
- 記録の検索、タグ絞り込み、一覧、詳細、編集、削除
- JSONバックアップ書き出しと復元
- オフライン利用を支援するPWA（HTTPS上で公開した場合）

## 保存について
記録はブラウザのIndexedDBに保存され、アプリ提供者のサーバーへ送信しません。写真は保存前に長辺1600px・JPEG品質82%に圧縮します。
ブラウザのデータ削除・端末紛失に備え、設定から定期的にJSONバックアップを保存してください。バックアップJSONには写真データも含まれるため、ファイルサイズが大きくなる場合があります。

## カード画像の自動認識について
この版はAI/API料金なしで動くことを優先し、写真からカード名・正逆を自動判別する機能は含みません。カード情報は写真を見ながら選択してください。選択したカード名と正逆位置はメモ欄へ自動反映されます。外部AI認識は別途API接続が必要です。

## 使い方
### まずローカルで試す
`index.html` をブラウザで開く方法もありますが、ブラウザによってPWA/保存機能の制限がある場合があります。安定利用にはHTTPSで公開する方法を推奨します。

### GitHub Pagesで無料公開（非公開データを保存する個人利用にも利用可能）
1. GitHubで新しいリポジトリを作成（例 `tarot-journal`）。
2. このフォルダ内のファイルをすべてアップロード。
3. Settings → Pages → Build and deploymentで、Deploy from a branch、`main`、`/ (root)`を選択し保存。
4. 公開URLをスマホで開き、ブラウザメニューから「ホーム画面に追加」または「アプリをインストール」。
5. 記録は各端末のブラウザ内に保存されます。別端末と自動同期しません。
